Determinístico: nenhuma posição usa Math.random; com “Animar” desligado o estado só muda quando você mexe num controle ou clica em “1 atualização”. “Nós dentro de #run-hud” é a métrica central: com o pool de marcadores ele sobe até o pico de marcadores simultâneos e para — se voltar a crescer a cada atualização, o pool regrediu. “Mutações de DOM/s” vem de um MutationObserver com childList+attributes+characterData em subárvore. Isto não é FPS: não há cena 3D, layout de terreno, shadow map nem GPU aqui. Para FPS, use o jogo. Servido pelo Vite: npm run dev e abra /docs/hud-perf-fixture.html.
